Architecture Overview

The Full I2V Pipeline

Modern I2V models are composed of several interlocking systems. We build each one from scratch, then wire them together at the end.

01 🖼️ Input Image + Text Conditioning
02 📦 Video VAE Encoder VAE
03 ⚡ Noisy Latents Flow
04 🔮 DiT Denoiser DiT
05 🎬 VAE Decoder → Video VAE

Inspired by WAN, Open-Sora, and CogVideoX architectures. Simplified for learning — no pretrained weights required.

Before You Start

Prerequisites

You don't need to be a diffusion expert. If you've worked with LLMs or basic PyTorch, you're ready to go.

🔥 PyTorch Basics Comfortable writing nn.Module subclasses and working with tensors.
🤖 Transformer Familiarity Self-attention, multi-head attention, positional encodings — the standard stack.
📐 Linear Algebra Matrix operations, projections. Calculus helps for the loss derivations.
🌊 Diffusion Intuition Helpful but not required. We explain the key ideas from first principles.
Quickstart

Get Started in 3 Steps

Clone the repo and open the first notebook. That's it.

1
Clone the repository
Grab the code from GitHub.
git clone https://github.com/Shubham2376G/NanoI2V.git
cd NanoI2V
2
Install dependencies
A standard PyTorch environment is all you need.
pip install torch torchvision einops jupyter
# optional: matplotlib for visualizations
pip install matplotlib
3
Open the first notebook
Start with causal 3D convolutions — the foundation of the video VAE.
jupyter notebook notebooks/01_causal_conv3d.ipynb
